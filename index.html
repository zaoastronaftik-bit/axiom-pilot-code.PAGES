Good to know

Questions,
answered simply.

Practical details about local AI, accounts, and what the preview includes.

Does AxiomPilotCode send my code to a cloud AI?

By default, the agent connects to a model served locally by LM Studio. Your project files and inference stay on your machine unless you deliberately configure another endpoint or execute commands that access the network.

Do I need a website account to use the CLI?

No. The current developer preview works locally without an account. Website accounts are for your profile; terminal account linking is still in development.

What can Fast and Deep do today?

Fast runs a direct agent workflow. Deep adds a planning pass before execution using the same model. Specialist multi-agent orchestration is on the roadmap.

Is AxiomPilotCode Pro available now?

Not yet. The Free account is available, but Pro features and pricing have not been launched.
