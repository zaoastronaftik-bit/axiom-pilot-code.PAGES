# AxiomPilotCode — website

Public landing page for [AxiomPilotCode](https://github.com/zaoastronaftik-bit/axiom-pilot-code), designed with a light glass interface and a blue/violet accent switcher.

## Hosting — GitHub Pages

This repository contains a **static site** with no build step.

1. Open **Settings → Pages** for this repository.
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**; click **Save**.
4. Wait for the Pages deployment to finish.

The free URL will normally be:

https://zaoastronaftik-bit.github.io/axiom-pilot-code.PAGES/

GitHub Pages links for project repositories include the repository name as a path.

## Files

- `index.html` — responsive light landing page with CSS and JavaScript embedded
- `favicon.svg` — the AxiomPilotCode mark

## Features

- Light-first glassmorphism with blur and subtle animations
- Blue/violet accent toggle
- Responsive landing with Fast/Deep showcase, features and pricing
- Account section marked **Coming next**

**No authentication is active.** This is a static landing page; Free/Pro are planned product tiers and Pro is not currently purchasable. The account modal never requests credentials. Supabase authentication and browser-to-CLI sign-in will be integrated later.

## Development

Open `index.html` in a browser. No Node.js installation or build system is required.

This project is hosted separately from the CLI source repository.
